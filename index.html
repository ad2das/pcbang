PC방 롤(LoL) 지연 최적화

두 가지가 있습니다: 재부팅 없이 바로 적용(PC방용) / 게임 부팅 모드(재부팅 항목까지 전부, 사무용 PC용). 어느 쪽이든 전부 원복할 수 있습니다.

쓰는 법

  • Win + X → 터미널(또는 Windows PowerShell)을 엽니다.
  • 아래 줄을 복사해서 붙여넣고 Enter. 관리자 권한 창이 뜨면 예를 누릅니다.
  • 롤은 게임(인게임)을 켜기 전에 실행하세요. 클라이언트는 켜져 있어도 됩니다.

0. USB 포트 확인 (따로 안 해도 됨 — 적용할 때 자동 확인)

2-A 적용과 게임 부팅 로그온 때 마우스·키보드 포트를 먼저 자동으로 확인합니다. 전부 초록이면 창 없이 그냥 진행하고, 빨강·노랑이 있으면 아래 창이 떠서 옮겨 꽂은 뒤 창을 닫으면 적용이 이어집니다(게임 부팅 로그온 때는 90초 뒤 저절로 닫힘). 미리 보고 싶을 때만 아래 줄을 쓰세요.

창이 뜹니다. 마우스를 움직이고 키보드를 아무 키나 누르면, 각각 어느 USB 컨트롤러에 꽂혀 있는지 바로 보여 줍니다. 빨강이면 다른 포트로 옮겨 꽂아 보세요. 꽂는 즉시 갱신되니 초록이 될 때까지 바꿔 보면 됩니다. 관리자 권한은 필요 없습니다.

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ad2das.github.io/pcbang/usb.ps1 | iex
  • 초록: 가장 좋은 컨트롤러(CPU 직결, 인텔은 메인 컨트롤러)에 직접 꽂힘. 노랑: 허브를 거침(앞면·모니터·키보드 포트) → 뒷면 포트에 직접. 빨강: 칩셋·추가 칩 컨트롤러이거나 블루투스.
  • 마우스와 키보드는 같은 컨트롤러에 같이 꽂아도 됩니다. USB 헤드셋은 가능하면 다른 컨트롤러로.
  • 적용이 끝난 뒤에 포트를 바꾸면 원복 → 다시 적용.

1. 점검만 (아무것도 안 바꿈, 재부팅 항목까지 전부 표시)

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ad2das.github.io/pcbang/check.ps1 | iex

2-A. 적용 — 재부팅 없이 (PC방용)

재부팅 없이 바로 먹히는 트윅만 적용합니다. 복원 프로그램이 있는 PC방은 이걸 쓰세요.

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ad2das.github.io/pcbang/run.ps1 | iex

2-B. 게임 부팅 모드 설치 — 재부팅 포함 (전부, 내 PC용)

사무용으로 쓰는 PC에서 게임할 때만 전부 켜는 모드입니다. 평소 부팅(사무)은 아무것도 안 바뀝니다.

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ad2das.github.io/pcbang/run-gameboot.ps1 | iex
  • 설치하면 숨겨진 "게임" 부팅 항목과 바탕화면 아이콘 게임 모드로 재부팅이 생깁니다. 부팅 메뉴는 안 뜹니다.
  • 게임하려면 아이콘 클릭 → 게임 부팅으로 한 번 재부팅. 재부팅해야만 먹히는 트윅(타이머 틱, 하이퍼바이저 끔, 커널·TCP·입력·GPU 레지스트리)까지 전부 + 2-A 트윅 전부가 로그온 때 자동 적용됩니다.
  • 그냥 재부팅하거나 껐다 켜면 사무 모드로 돌아오고, 로그온 때 2-A 트윅도 자동으로 원복됩니다.
  • 게임 부팅 중엔 하이퍼바이저가 꺼져 WSL2·Hyper-V·일부 에뮬레이터가 안 됩니다(사무 부팅은 그대로).
  • BitLocker가 켜진 PC는 모드를 바꿀 때마다 다음 한 번의 부팅 동안 보호를 잠깐 멈춥니다(복구 키 요구 방지).
  • 복원 프로그램이 있는 PC방에서는 재부팅하면 다 지워지니 쓰지 마세요(2-A를 쓰세요).

3. 원복

어느 쪽이든 이 한 줄로 되돌립니다. 게임 부팅 모드는 사무 부팅에서 실행하세요(게임 부팅 항목, 아이콘, 자동 작업까지 삭제).

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ad2das.github.io/pcbang/revert.ps1 | iex

알아둘 것

  • 마우스·키보드를 다른 USB 포트로 옮기면: 원복 → 다시 적용.
  • 적용 중 몇 초간 마우스/키보드/화면이 끊길 수 있습니다(USB 컨트롤러 재시작). NIC 설정이 바뀌면 인터넷도 잠깐 끊길 수 있습니다.
  • 롤 설정은 지연 관련 4개만 바꿉니다: 전체화면, 수직동기화 끔, 이동 예측 끔, 프레임 제한. 그래픽 품질·마우스 감도는 안 건드립니다.
  • 다운로드 파일은 SHA-256으로 검증하고, 다르면 실행하지 않습니다.
