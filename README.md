# pcbang

PC방에서 리그 오브 레전드(LoL) 입력·네트워크 지연을 줄이는 원클릭 스크립트입니다. 재부팅 없이 바로 적용하는 모드와, 재부팅이 필요한 트윅까지 숨겨진 게임 부팅 항목에만 넣는 게임 부팅 모드가 있습니다. 전부 원복할 수 있습니다.

사용법은 https://ad2das.github.io/pcbang 을 보세요.

- `usb.ps1`: USB 포트 점검 창. 마우스·키보드가 어느 USB 컨트롤러에 꽂혀 있는지 실시간으로 보여 줍니다. 아무것도 바꾸지 않고, 관리자 권한도 필요 없습니다.
- `check.ps1`: 점검만 합니다. 아무것도 바꾸지 않습니다.
- `run.ps1`: 재부팅 없이 적용합니다.
- `run-gameboot.ps1`: 게임 부팅 모드를 설치합니다(숨겨진 부팅 항목 + 바탕화면 아이콘). 평소 부팅은 그대로입니다.
- `revert.ps1`: 원복합니다(게임 부팅 모드는 사무 부팅에서 실행).
- `pcbang-<sha>.ps1`: 실제 스크립트입니다. 위 런처들이 SHA-256을 검증한 뒤 실행합니다.
